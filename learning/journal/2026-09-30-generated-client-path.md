# Generated TypeScript Contract Path

## What did we add?

A pinned OpenAPI-to-TypeScript generator, committed generated Foundation types, a stale-output check, and web compilation against those types.

## Why does LifeOS need it?

The web client should consume the server contract from one source instead of maintaining duplicate request and response shapes by hand.

## What should JIALE learn later?

Study schema-driven generation, deterministic committed artifacts, drift checks, type-only imports, and why generated DTOs still do not contain business rules.
