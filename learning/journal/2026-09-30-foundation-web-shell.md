# Foundation Web Shell

## What did we add?

A minimal accessible React/TypeScript/Vite shell, a small API boundary, pinned npm metadata, tests, type checking, and production build commands.

## Why does LifeOS need it?

The shell proves the replaceable web toolchain and browser/server boundary before product UI and business behavior are introduced.

## What should JIALE learn later?

Study npm workspaces and lockfiles, Vite build-time environment values, accessible status feedback, and why components call a typed API boundary instead of implementing domain rules.
